Redis

Um depósito de dados na memória. A aplicação pergunta pela chave e a resposta chega em milissegundos — não em um disco.

O que é

Chave → valor, só que em RAM.

Redis é um servidor que guarda pares na memória do computador. Você escreve um nome (a chave) e um conteúdo (o valor). Depois lê de volta pelo mesmo nome. Não substitui um banco relacional: fica na frente dele, para o que precisa ser instantâneo.

SET user:42 "{ nome: Thomaz }"
GET user:42 → 1 ms

Exemplo

A mesma página, dois caminhos.

Sem Redis

  1. Pedido chega
  2. Consulta o SQL
  3. Disco gira, índice, join
  4. Resposta em ~80–200 ms

lento demais para o mesmo HTML 10 mil vezes

Com Redis

  1. Pedido chega
  2. GET pagina:home
  3. Já está na RAM
  4. Resposta em ~1 ms

o SQL só entra se a chave não existir

Para que serve

Quatro usos que você já viu.

  • 01

    Cache

    Guarda o resultado caro (HTML, JSON, query) e reusa.

  • 02

    Sessão

    Login, carrinho, token — some se o servidor cair? Não, se estiver no Redis.

  • 03

    Ranking

    Placar ao vivo: sorted set. Quem mais pontuou sobe sozinho.

  • 04

    Fila / pub-sub

    Um processo publica, outro escuta. Desacopla quem produz de quem consome.

Por que é rápido

RAM não espera o disco.
